Jeeves

Jeeves is a private, personal assistant used only by its owner. It is not a public service, and no one else can sign in to it.

Privacy policy

With the owner’s permission, Jeeves reads the owner’s own Gmail account (read-only) to sort email, track bills, packages and refunds, and suggest replies.

  • Jeeves cannot send, delete or change email. It only reads.
  • Email content is processed by Anthropic’s Claude API only to sort and summarize it for the owner.
  • Data is kept on the owner’s own computer. It is never sold, shared, or used for advertising.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be removed at any time in the Google Account, under Security → Third-party connections.
